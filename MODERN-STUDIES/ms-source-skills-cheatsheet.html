Modern Studies: Source Skills

Exam Tue 19 May  ·  30 of 80 marks
Universal rules (all 3 questions)
Use all sources for full marks ⚠ 2 sources = max 6 ⚠ 1 source = max 4 Always say "Source 1 shows..." Max 3 marks per developed argument
Question type A
Conclusions
10
What to do
1
Draw one conclusion per bullet point (4 bullets = 4 conclusions)
2
Support each conclusion with evidence from the sources
3
Use evaluative language to reach 3 marks
Marks What you need
1 Basic conclusion OR ID info from source — no evidence
2 Conclusion + 1 piece of source evidence
3 Conclusion + 2 pieces evidence + evaluative language
Watch out
  • Write "Overall..." to signal a real conclusion
  • Cross-reference 2 sources in at least 1 answer
  • Don't just copy numbers — interpret them
Question type B
Options / Recommend
10
What to do
1
State your recommendation at the very start: "I recommend Option 1 because..."
2
Justify your choice with 3–4 developed arguments using source evidence
3
Reject the other option — explain why it is worse, using source evidence
Cap Condition
Max 8 Only justify chosen option, no rejection
Max 3 Any single justification point
Watch out
  • You must reject the other option for full marks
  • Don't forget to say which option you picked
  • Use evidence to reject, not just opinion
Question type C
Support / Oppose
10
What to do
1
Explain why the given view is SUPPORTED by the sources (2–3 points)
2
Explain why the given view is OPPOSED by the sources (2–3 points)
3
Each point: state → explain → link to source evidence
Cap Condition
Max 6 Only argue one side — biggest trap!
Max 3 Any single developed argument
Watch out
  • Not the same as Options — you do NOT recommend. You argue both sides.
  • Start: "The view is supported because..."
  • Then: "However, the view is opposed because..."
Key phrases to use in every answer
Overall, ... This shows that ... This suggests that ... This indicates that ... Source 1 shows that ... According to Source 2, ... This is supported by Source 3, which states ... Therefore, ... This demonstrates that ... In contrast, Source 2 shows ... However, the view is opposed because ...
